So geht's
  1. Auf „Einladung annehmen“ tippen. Dein Einladungslink wird dabei kopiert.
  2. Breadbox laden und anmelden.
  3. Breadbox fragt, ob du die Einladung einfügen möchtest. Auf „Einfügen“ tippen und bestätigen.
  4. Auf „Einladung annehmen“ tippen und Breadbox installieren.
  5. Anmelden.
  6. Breadbox zeigt dir die Einladung. Bestätigen, fertig.
  7. Breadbox aus dem Store laden und anmelden.
  8. Unten auf „Breadbox“ tippen, dann „Die Küche“, das Plus und „Du hast selbst einen Code bekommen?“.
  9. Den Code von oben eingeben und auf „Einlösen“ tippen.
  10. Breadbox aus dem Store laden und anmelden.
  11. Nach deinen Freunden suchen und auf „Anfrage“ tippen.

Hat das nicht geklappt? In Breadbox unten auf „Breadbox“, dann „Die Küche“, das Plus und „Du hast selbst einen Code bekommen?“ – dort den Code von oben eingeben.

Du hast Breadbox schon? Aktualisiere sie im Store und tipp den Link danach nochmal an.
